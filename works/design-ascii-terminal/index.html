FESTIVAL(1) ISLAND RESONANCE — User Manual FESTIVAL(1)
NAME
island_resonance — 台灣東岸獨立音樂節，2026 第六屆。在島嶼盡頭，聽見彼此的迴聲。
SYNOPSIS
festival [--edition 6] [--days 3] [--stages 3] [--bands 12] [--venue duulan-bay]
DESCRIPTION
「島嶼共鳴」自 2021 年由 浪打文化 於台東創辦，本年邁入第六屆。
它不只是一場音樂節，更是台灣獨立音樂與東部自然地景對話的場域—— 把後搖、夢幻流行、噪音、電子、Indie Folk 與世界音樂， 和都蘭部落的山海節奏編進同一個三日通道裡。
DESIGN GOAL
強調 環境永續：所有飲料杯使用押金循環杯系統、無一次性塑膠； 與都蘭部落及在地店家共組 「島嶼夥伴計畫」，把節慶能量留在地方。

[A] 共鳴山主舞台 / Resonance Mountain Stage cap = 8,000

都蘭灣山坡草地、面海背山的 360° 環繞音場。三組頭條都在這座主舞台壓軸登場——白日吹著太平洋的鹹風，入夜後燈光從山脊往海面打出，聲音像漣漪一樣一圈一圈推出去。

[B] 海風舞台 / Sea Breeze Stage cap = 3,000

直接在沙灘上搭建、距離浪線最近的舞台。夕陽時段最魔幻，赤腳可以直接入場踩進細砂裡聽 Indie Folk、Ambient、Shoegaze——把腳印留在潮間帶的版本。

[C] 部落舞台 / Tribe Stage cap = 800

由都蘭木造倉庫改建、限量手環入場的親密 livehouse。空間小到能看見鼓手手汗，是 Jazz Fusion、Punk、World Music 在夜裡互換體溫的所在。

# Last updated: 2026-05-01 — 交通與住宿須知

1. 自行開車 / Drive Yourself

從台北經 國道 5 號（雪山隧道） 轉 台 9 線 南下，至都蘭灣海岸自然公園約 4.5 小時 車程。
場區設有付費停車場：單日 NT$ 200 / 三日 NT$ 500。建議多人共乘以減少碳排——車裡塞滿朋友是最省油的隊形。

2. 大眾運輸 / Public Transit

搭乘台鐵或高鐵 + 轉乘抵達 台東車站 後，主辦方提供 免費接駁巴士，車程約 25 分鐘。
發車窗口：09:00 – 12:00 與 13:00 – 17:00，兩個時段內每 30 分鐘一班。

3. 住宿建議 / Stay

  • 場區內 帳篷營位：NT$ 800 / 晚（含早餐券、淋浴間使用）
  • 合作民宿：都蘭、東河沿線 12 家 配合民宿（優惠碼 ISLAND2026 享八折）
  • 露營車租賃：與「島嶼漫遊」合作，三日方案 NT$ 9,800 起

HELP(--) festival --help · FAQ HELP(--)
Usage: festival [OPTIONS]
Options below cover the 7 most common questions. Run festival --help-all for more.
雨天如何處理？
本活動為雨天照常舉行，僅在劇烈雷雨或主辦方判斷有安全疑慮時暫停演出；如完全取消，依退票政策辦理。
可以攜帶寵物嗎？
為維護動物與觀眾安全，本活動全區禁止攜帶寵物；導盲犬、輔助犬請於入口出示證明。
兒童入場規則？
12 歲以下兒童由父母陪同免票入場（每位購票者最多攜帶 2 名兒童），需配戴主辦方提供的螢光手環。
可以自備食物或外食嗎？
可攜帶輕食與飲水（限玻璃以外容器），場內提供 30 家風味攤位，鼓勵支持在地餐飲。
場內可以搭設帳篷嗎？
僅限購買「帳篷營位」方案者於指定營區搭設，請依現場標示，禁止占用一般草地。
無障礙設施？
三舞台均設無障礙觀賞區與專用通道，輪椅租借請於官網表單預約，現場備有 20 台輪椅。
可以攝影錄影嗎？
歡迎個人手機與小型相機紀錄；商業攝影（含腳架、長焦、無人機）需另外申請媒體證。
