「島嶼共鳴」自 2021 年由浪打文化於台東創辦，2026 邁入第六屆——這不只是音樂節，而是台灣獨立音樂與東部自然地景對話的協議層。

三日 25,000 人次、12 組亞洲樂團、3 個與環境共生的舞台，於都蘭灣海岸自然公園展開為期 72 小時的低延遲共鳴。

環境永續模組已啟用：所有飲料杯使用押金循環杯系統，全區域 0 一次性塑膠，並與都蘭部落、在地店家共組「島嶼夥伴計畫」，於地方節點建立互助協定。

MODULE_08 / FAQ_BUFFER

常見問題 / FAQ

// QUERY_RESPONSE_TABLE // 07 ENTRIES
> 終端機常見查詢介面，點擊問題以展開回應緩衝區。
Q01 :: 雨天如何處理？
本活動為雨天照常舉行，僅在劇烈雷雨或主辦方判斷有安全疑慮時暫停演出；如完全取消，依退票政策辦理。
Q02 :: 可以攜帶寵物嗎？
為維護動物與觀眾安全，本活動全區禁止攜帶寵物，導盲犬、輔助犬請於入口出示證明。
Q03 :: 兒童入場規則？
12 歲以下兒童由父母陪同免票入場（每位購票者最多攜帶 2 名兒童），需配戴主辦方提供的螢光手環。
Q04 :: 可以自備食物或外食嗎？
可攜帶輕食與飲水（限玻璃以外容器），場內提供 30 家風味攤位，鼓勵支持在地餐飲節點。
Q05 :: 場內可以搭設帳篷嗎？
僅限購買「帳篷營位」方案者於指定營區搭設，請依現場標示，禁止占用一般草地。
Q06 :: 無障礙設施？
三舞台均設無障礙觀賞區與專用通道，輪椅租借請於官網表單預約，現場備有 20 台輪椅。
Q07 :: 可以攝影錄影嗎？
歡迎個人手機與小型相機紀錄；商業攝影（含腳架、長焦、無人機）需另外申請媒體證。
